# legion-trailer-render

Render pipeline for the [Legion](https://github.com/dnh33/legion) trailers. Edit `render.json` and push, or use
Actions → Render trailer; the files appear under Releases. Only what a render needs lives here. Each Release also carries a review pack (`review/`: contact sheets, every hard cut before/on/after, an audio report) made by `tools/review.py`, so a render can be reviewed without rendering anything locally.
